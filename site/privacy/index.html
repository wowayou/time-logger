隐私政策

最后更新：2026-07-31

1. 我们收集什么：什么都不收集。

应用不采集、不上传、不同步任何数据；无账号、无后端、无分析、无广告、无第三方脚本、无 Cookie。

2. 你的数据存在哪里。

全部记录只存在你浏览器的 localStorage（键 timelog.v1、timelog.config、timelog.locale 等），只在你这台设备上。清除站点数据或卸载 PWA 会删除记录——请定期导出备份。

3. 托管。

本站由 GitHub Pages 静态托管。任何网站的托管方在提供页面时都会按常规记录访问请求（IP 地址、User-Agent 等传输层日志）；本项目不接触、不留存、不分析这些数据，也不向其中注入任何标识符。

4. 数据可携带。

完整备份可随时复制、下载或分享为 JSON，免费、不需要账号、不需要网络。

5. 儿童。

应用不面向儿童定向收集任何信息——因为不收集任何信息。

6. 变更。

政策变更会更新本页顶部的「最后更新」日期；变更历史可在公开仓库的 Git 历史中查证。

7. 联系方式。

GitHub issues：github.com/wowayou/time-logger/issues · 主页：eigentime.org
