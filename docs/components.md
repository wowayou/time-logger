# 按钮组件清单

> SPEC-016 B 期（v1.15.8）。本表是**登记处**：`scripts/project_audit.py` 的 `audit_button_inventory` 从运行时模板（`src/*.js` 的 `<button class="…">` 与 `createElement('button')` 后的 `className`、`index.html`）收集每个按钮的第一个静态类名，要求它在下表出现；表里登记了、模板里已不存在的类也会报错。新增按钮先决定它属于哪个家族、沿用该家族的规则，再登记一行。
>
> 共同规则：焦点环由全局 `:where(button, a, input, textarea, select, [tabindex]):focus-visible`（2px `--accent`、外偏 2px）提供，下表「焦点」只写偏离它的组件；按下反馈默认是 `opacity: 0.75`；触控热区以 44×44 为项目主要基线（2.5.8 AA 为 24×24 含例外，见 CLAUDE UI 红线）。字号与圆角一律用令牌（`audit_css_tokens`）。

## 家族

| 家族 | 外观 | 何时用 |
|---|---|---|
| 整行动作 | 浅色底、正文字号 600、高 48、圆角 `--r-ctl`、两侧 `--sp-3` | 表单或面板里「这一块要做的事」：切一刀、删除这条、复制本期摘要、标签设置里的确认两键 |
| 次要文字动作 | 无底、主色 600 字的文字链 | 行内或提示里的轻动作：补一下、标记已发生、确认、清空、不选、改选、段首/段尾 |
| 表头动作 | sheet 头部左右文字键 | 取消 / 完成 / 关闭 |
| 导航与分段 | 壳面（`--chrome`）或分段控件 | 切视图、切周期、切图形、翻页 |
| 可点的行与面 | 整行即按钮，悬停有浅底（精确指针） | 时间轴行、明细行、事项排行、正在做、格言、联想项、标签 chip |
| 浮层与提示 | 固定定位 | 记一条、撤销、更新应用 |
| 时间选择 | 选择器内部控件 | 触发行、现在、日历、步进 |

## 间距

A 期顺延的半档与奇数间距（§7 清单）不在本期批量替换：它们决定各组件的节奏，统一到 4px 刻度会让整页每个组件挪 1–2px，截图对照也会被差异铺满。本期只在实际收敛的组件里清掉重复声明，像素不变；改某个组件时再按组件收敛，并以截图对照证明只有该组件变化。
