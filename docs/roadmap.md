# 候选路线图

> 本页记录候选与评审边界，不是排期。当前执行项见 [STATUS.md](../STATUS.md)；功能扩张门槛见 [CLAUDE.md](../CLAUDE.md#v2-锁死--别镀金)。达到「28 天真实记录 + 求职有实质进展」只允许重新评审，不自动开工。
>
> 更新：2026-09-30。以下保留原 R 编号，区分已经交付的最小方案与仍未放行的扩张。

## R1 · 性能与内存

以可复现的真实卡顿为前提，先测量再决定优化。v26 的资源体积与早期 Chromium 单引擎毫秒数已不能代表当前版本，不再作为现状引用。

现行护栏在 [tests/stress.spec.js](../tests/stress.spec.js)：启动用加载数据相对空数据的增量预算，完整年视图另测耗时及配置读取次数。它们测量的是自动化环境中的页面路径，不代表 iOS 主屏冷启动。真机冷启动取证见 [故障记录 P33](postmortems.md)。

没有新证据时，不主动做虚拟滚动、模块懒加载、图标瘦身或框架迁移。

## R2 · 降低记录阻力与原生入口

- **已落地的网页最小方案**：v1.4.0 的「正在做：X · 已 Ymin」状态条，展示现有进行中段并可点击编辑；没有增加开始/停止计时模型。范围见 `CLAUDE.md` v1.4.0 记录。
- **安卓例外已放行**：D26 批准独立仓库内嵌 Web 运行时并提供原生入口；进度见 `STATUS.md`，不改变本仓无构建、零运行时依赖的边界。
- **仍未放行**：iOS Widget、锁屏实时活动、快捷指令直达等独立候选。iOS 系统小组件与实时活动需要原生载体，按 D17 评审；网页入口需先证明现有记录流程存在重复摩擦。
- **提醒推送不在当前范围**：不能将 Web Push 写成零后端网页方案；远端推送需要额外服务，触及现行架构与隐私边界。

## R3 · 使用里程碑与全局用户数

**本地替代已实现**：v61 起显示「记录历程第 N 天 · 已记录 N 天」，只从真实、非计划、非占位记录派生。它不等于安装天数、人工判断的有效记录日或全局用户数。

**全局第 N 位使用者不做**：本项目没有后端、遥测或可靠安装计数。GitHub Stars、访问量、下载量不能冒充真实使用人数，也不使用写死数字或设备指纹制造社会证明。未来若提出远端匿名计数，需另行评审架构与隐私边界。

## R4 · 访问统计（候选，未放行；2026-10-01 分析）

维护者问：想追踪 `time.eigentime.org/app` 的访问情况，是否只能把部署从 GitHub 迁到 Cloudflare。结论：**不必迁移托管，但任何统计都要先改隐私承诺并另立决策**。

- **现状事实**（2026-10-01 `dig` / 响应头核对）：`eigentime.org` 的 DNS 已托管在 Cloudflare（NS 为 `*.ns.cloudflare.com`，主站已走代理）；`time.eigentime.org` 是指向 `wowayou.github.io` 的 **DNS-only** CNAME，由 GitHub Pages 直接响应（`server: GitHub.com`）。GitHub Pages 不提供自定义域名的访问统计。
- **最小方案**：把 `time` 这条 CNAME 在 Cloudflare 里切成「代理」（橙云），就能在 Cloudflare 看到**零 JS、零 Cookie** 的聚合流量（请求数、带宽、按 IP 估算的独立访客、国家；免费版能按路径细分到什么程度以控制台实际为准）。托管、发布流程、镜像仓库都不用动。
- **前提与代价**：
  1. **隐私承诺先改**：主页写着「零追踪」「本站不加载任何统计」，隐私政策写着「无分析……托管日志本项目不接触、不留存、不分析」。开启任何统计前必须先改这两处（中英四页）并记一条决策（D32），否则就是对外口径失信——比没有统计更伤。
  2. **HTTPS 证书**：GitHub Pages 为自定义域签发/续期证书需要看到直连解析，开代理后 Cloudflare 的 SSL 模式要设为 Full，并留意续期失败这一常见坑；launch-runbook B 的「Enforce HTTPS」尚未核验，应先核验再动代理。
  3. **PWA 让数字失真**：装过的用户打开 `/app/` 由 Service Worker 缓存直接响应，不经过网络；服务器只看到首访和回到前台时的 `sw.js` 更新检查。所以「访问量」≈ 首访 + 更新检查次数，**不是使用次数、更不是用户数**，对外不得当成用户数说（D3）。
- **不推荐**：Cloudflare Web Analytics 的 JS 信标（往页面注入第三方脚本，直接违背「无第三方脚本」；应用内埋点另被 D27/D28 禁止）；仅为统计而迁到 Cloudflare Pages（要重做 publish-site、证书、旧地址跳转，得到的统计能力与「代理」基本相同）。
- **放行条件**：维护者明确需要一个具体数字来做某个决定（例如判断推广是否带来首访），且接受先改隐私承诺；否则维持现状——首轮推广的有效信号是回帖里的具体反馈，不是访问量（checklist §0）。
