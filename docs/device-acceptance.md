## #45 · 系统返回与帮助问答（v1.15.4，与 RC1 同运行时）

**三星 Galaxy S23（SM-S9110），Android 14，Chrome 153.0.8010.47，隔离来源 localhost:8764。** Chrome「安装并创建快捷方式 → 安装」后，还需在三星桌面确认「添加」。由桌面图标进入，核对来源、`display-mode: standalone`、更多页版本 1.15.4。以下触摸/返回经 USB 在真机上注入，不是模拟 Esc，也不是人工手感评估。

- 边缘滑回：展开说明后依次回更多、时间轴；输入合成草稿，确认键盘显示，第一次只收键盘、第二次关表单，重开恢复草稿。保存合成记录后，从编辑发起删除确认，滑回编辑，再滑回时间轴，记录、配置、句库原始值与取消前一致。根界面再滑回，前台回到三星桌面。
- 系统文件选择器退出后仍在备份页，再发送系统 BACK 键，逐层回更多和时间轴。选择器里有多次返回，不能认定一次就退出，也未选文件测试导入预览。
- 后续三键补验：普通 Chrome 页与桌面独立窗口分别核对。唤出底部导航栏后点实际返回箭头，已展开答案的说明 → 更多 → 时间轴；左滑合成记录发起删除，取消直接回时间轴；用合成文件进入导入预览（经页面文件输入事件，不确认写入），一次返回只退一级，依次回备份页、更多、时间轴。三项前后均核对记录、标签配置与句库原始值相等。已恢复原手势导航，未操作正式来源的数据。
- 系统文件选择器（DocumentsUI）单独打开验证：点一次可见返回箭头仍在系统文件界面，后续系统返回退出时独立窗口仍在备份页。此处由系统处理，不保证一次关闭原生文件选择器；没有观察到同时关闭下方面板。不代表其他机型、系统版本或 iOS 已验。

Windows + WSL 本地操作：使用发布页附件 `time-logger-1.15.4-rc1-app.zip` 或从本候选工作树 `python3 scripts/build_site.py --out "$(mktemp -d)" --no-cname` 得到 `app/`。只提供应用目录，勿在仓库根目录开文件服务器，不使用真实记录。

1. 手机打开开发者选项和 USB 调试，用数据线连电脑、解锁并同意调试授权。WSL 执行 `adb.exe devices`，应恰有一台状态为 `device`（`unauthorized` 看手机授权，空列表检查线缆）。
2. 下载附件后的方式：在 WSL 进入 ZIP 所在目录，执行 `DIR=$(mktemp -d)`、`python3 -m zipfile -e time-logger-1.15.4-rc1-app.zip "$DIR"`、`python3 -m http.server 8764 --bind 127.0.0.1 --directory "$DIR/app"`，保持此终端运行。
3. 另一 WSL 终端执行 `curl.exe --noproxy "*" -fsS http://127.0.0.1:8764/manifest.webmanifest`，确认 `1.15.4`。执行 `adb.exe reverse tcp:8764 tcp:8764`。若端口被占用，换一个空闲端口，电脑、转发两端、手机都要一致。
4. 手机 Chrome 普通窗口访问 `http://localhost:8764/`，用浏览器菜单「安装应用」；从新图标启动，确认无地址栏、「更多」底部为 1.15.4。只创建了浏览器快捷方式时不能记作独立窗口已验。请勿卸载正式版或清理正式站数据。
5. 打开「更多 → 说明」，点问题行左侧文字、再点右侧箭头，两处均可整行开合；展开后箭头朝下、答案与该问题相邻。试长英文和深浅主题。不必关掉当前问题才能打开另一个。系统返回应回到更多，下一次才到时间轴。
6. 按下表测试。从安卓设置切换「手势导航」和「三键导航」，各走一遍。结果格式：机型 / Android / Chrome / 应用版本 / 导航方式 / 步骤 / 一次返回后的实际页面与数据。未测写未测，不记录设备序列号或个人备份。
7. 结束时 `adb.exe reverse --remove tcp:8764`，服务器窗口按 Ctrl+C。如只为本次调试开启 USB 调试，可在手机设置中关闭。

在独立测试来源安装到 Android Chrome 主屏，确认「更多」里的版本，从图标冷启动。记录机型、系统、Chrome 版本、导航方式与每步实际结果。边缘滑回与三键导航的返回键分开走一遍；不要拿桌面 Esc 或 `requestClose()` 代填。原生能力不可用时只保留现有应用内关闭，不承诺拦下系统离开。

| 入口 / 操作 | 一次返回的目标与数据边界 |
|---|---|
| 新建，输入合成正文，键盘仍打开 | 系统先收键盘，文字与面板仍在；再返回时间轴，不新增记录，同入口重开恢复草稿 |
| 编辑时改字后返回；从编辑或时间轴分别打开删除确认 | 编辑取消不改原文；取消删除分别回编辑或时间轴，记录不删、无撤销横幅 |
| 更多 → 备份与导入 → 系统选文件；取消选择；再选文件进入导入检查 | 系统文件层先退、备份页仍在；检查页退回备份页，换文件不沿用旧冲突选择；再依次回更多、时间轴。无写入 |
| 从更多分别进入说明、标签设置、高级；新建表单宽布局打开日历 | 每次退一层，不跳过父菜单；日历先收。最外层关闭后可继续操作原入口 |
| 快速返回、取消后立刻重开、保存/分析下钻后再返回 | 一次请求不执行两次，关闭动作不误保存；主界面无隐形弹层或空历史步，返回交还系统。按钮、遮罩、Esc、短菜单下拉保留 |

**任务基线与放行分开**：在正式版与候选分别用同一合成数据走「首次记一条、重复记一条、补昨天一段、看本周最多事项、完整 JSON 迁到干净环境」。不提示入口；每条记起止耗时、折返/求助、保存后的时间/标签或恢复结果。首次和熟练任务不混算，不拿脚本耗时证明“5 秒”。旧安装带数据点更新、飞行模式重开并记录后核对数据。没有真机数据时这些项均待验；iOS 主屏单列体验，不承诺 Android 手势。

## 长段提醒（按现行规则核对）

- 默认关闭：明确标签段按原桶统计，不要求确认。
- 「更多 → 高级」开启后：超过 3h 且未设免确认的段出现待核提醒，**桶与分钟数不变**。
- 过夜续记不得自动盖确认章；已关闭段可确认，确认只清除提醒，边界改变后提醒可重新出现。
- 导入完整备份不替用户开启本机待核开关。

## 通用抽查

- 键盘开合时表单头部可见、面板不跳动；长设置页末行可滚到且可点。
- 主题和语言从「更多」切换；已有标签名不随语言改变。
- 「更多 → 备份与导入 → 导入检查」逐层返回；可见性检查包括是否在视口内及是否被遮挡。
- 删除记录后最多 8 秒可撤销；下一次其它交互或跨标签页修改使撤销结束，直接点撤销本身可恢复记录。
- 后台停留后回前台，或前台被冻结后触摸/滚动，时间更新到当前分钟。
- 系统动效或状态栏问题先做跨应用对照；无头浏览器不能代替真机系统界面验收。
