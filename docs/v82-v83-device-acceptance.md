## A · v82 删除

入口：「···」→ **标签高级设置**

| # | 操作 | 期望 |
|---|---|---|
| A1 | 看常用标签行 | 第二行右侧是「**N 条记录**」，**没有**删除入口 |
| A2 | 看没用过的标签行 | 第二行右侧是红色「**删除**」 |
| A3 | 点一次「删除」 | 该行变灰、名字划线、输入框禁用，按钮变「撤销」；其它行不受影响 |
| A4 | 点「撤销」 | 行恢复正常 |
| A5 | 再点「删除」→ 右上「**保存**」 | 回到「更多」；重开设置页，那一行已消失 |
| A6 | 找个**有记录**的标签，清空名字 → 保存 | 报错「标签名不能为空；不想要这个标签就点「删除」。」，且**没有任何东西被删掉** |
| A7 | （可选）把某组零记录标签全删 → 保存 → 重开 | 该组显示空态提示，下面仍有「＋ 新建标签」 |

## 本轮真机反馈（2026-08-04，维护者）

验收结论「基本可以」，同时提出 8 条调整项。**裁决尚未作出**——待维护者拍板后另立决策记录，届时本节改为索引：

1. 空名报错后视图自动滚到最底部（错误提示挂在正文末尾）——**缺陷**。
2. 中英文标签并存（`睡觉` 与 `Sleep`）、`sleep` 与 `Sleep` 视为两个标签——**缺陷 + 缺失能力（合并）**。
3. 标签管理是否需要多选——**待定，先看合并能否解决**。
4. 删除记录的撤销横幅停留过久——**参数问题，牵动 8 秒撤销窗口红线**。
5. 「更多」面板过长——**结构问题**。
6. hero 的 `~` 前缀不够优雅——**表达方式问题**。
7. 退出动效白边（Android S23）——**待定位，需一次对照实验**。
8. 交互整体参考 joi.com 的 PWA——**方向性输入，不构成改动项**。
