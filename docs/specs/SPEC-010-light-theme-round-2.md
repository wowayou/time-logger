# SPEC-010 · 亮色冷白第二轮打磨（图底关系修复；先出变体截图、维护者拍板后才发版）

status: done（阶段一变体 A 经维护者 2026-07-26 拍板；阶段二随 PR #31 / v75 发布，含 faint/danger 无障碍修正与 WCAG 永久护栏）
owner: 执行方认领后填分支名
验收人: Fable（视觉终审：维护者）

## 背景与诊断

v72 冷白上线后维护者真机判词：「勉强能看，但还是不够舒服」。Fable 对 v72 亮色截图的设计诊断：**色相方向（冷）是对的，塌掉的是图底关系**——`--bg #f7f7fa` 与 `--card #ffffff` 明度差过小，页面退化成「三种接近的白」（底/卡/input pill），层级全靠阴影硬撑；日视图下半屏时间轴容器是一整块无锚定的白板，观感发飘、晃眼。暗色主题的层级逻辑（面比底亮、有骨架）在亮色里没有等价物。

这是亮色第三轮调整（D11 一档折中 → SPEC-004 整体冷白 → 本轮），**不允许再盲发**：本规格采用两阶段，先便宜看图、后昂贵发版。

## 两阶段执行

### 阶段一：三个令牌变体（只改本地、不发版、不 bump）

在冷白色相内做三个变体，各出双主题截图（day 视图 + 更多 sheet + 标签设置，320px 与 390px），贴 PR（draft）供维护者挑选：

- **变体 A（主推）·底色下沉一档**：`--bg` 降到 `#eceef3` 区间（冷灰纸），`--card` 保持纯白——白卡靠真实明度差「浮」起来，阴影回归辅助；`--input` 相应调到与新底有分离（约 `#e2e5ea`）；hairline 可微降存在感。
- **变体 B·双面色分层**：`--bg` 维持 `#f7f7fa`，但给日志容器/大面积区一个介于底与白之间的冷面色（新令牌或复用 `--input` 系），页面从「白上白」变「白-灰白-白」三层。
- **变体 C·骨架加重**：底/卡不动，`--border` hairline 加深一档 + `--text` 系墨色微沉，靠线与墨锚定层级（改动最小、风险最低，但对「发飘」的救治力也最弱）。

每个变体附 WCAG 关键比值速算（正文/muted/danger 对底与对卡）。**维护者选定（或指出混搭）前不得进入阶段二。**

### 阶段二：按拍板结果定稿发版

- 全量令牌落 `styles.css` 两处亮色块；theme-color 锚点（index.html/app.js）与 `site/index.html` 亮色 `--bg` 同步跟随；暗色一字不动。
- WCAG 全量重校贴数（≥ v72 记录值或 ≥ AA）；P22 滚轮层序回归绿；三桶彩色对新底比值贴数。
- bump 按当时序列 + CHANGELOG 行（写明三轮历程与本轮两阶段流程）；全套自测绿；双主题定稿截图。

## 明确不做

- 不回暖色（方向已定冷）；不动暗色；不动布局/间距/字阶；阶段一不合并任何代码。

## D15 额度裁剪修订（2026-07-25，维护者批准）

阶段一收敛为**只出变体 A（底色下沉一档）**，B/C 不做。理由：三变体 ×（day/更多/标签设置）×（双主题）×（320/390）是十余张截图的产出与评审成本，而 A 本就是本规格自己的主推方案；「先便宜看图、后昂贵发版」的初衷用一个变体同样成立。A 若被否，按维护者的口头方向出第二个变体——那时是有信息的一轮，比盲选三选一更省。

排期：排在 v74 合并批次（SPEC-012 + SPEC-011 + SPEC-009-lite）之后。若维护者在 v74 发版前拍板通过 A，阶段二可并入 v74 同一次仪式；否则走下一次仪式。**阶段一仍然不合并任何代码、不 bump。**

## 阶段二落地记录（2026-07-26，v75）

阶段一只出变体 A（D15 裁掉 B/C），维护者拍板采纳，并追加要求**同批修 `--faint` / `--danger`**——阶段一的 WCAG 速算暴露出这两个令牌**在当时已发布的 v74 就低于 4.5**（4.28 / 4.03），变体 A 会把它们压到 3.94 / 3.71，而 `--danger` 是真实错误文案的颜色。

最终落地＝规格原范围（`--bg`/`--input`/`--border` + 三处锚点）＋ `--faint: #66646d`／`--danger: #ae414f`＋ `project_audit.py` 新增 WCAG 永久护栏（亮暗双主题 + 着陆页，低于 4.5:1 即 fail）。

**验收抓到的一处漏网**：`site/index.html` 维护着自己一套内联令牌，执行方只同步了它的 `--bg`、漏了 `--faint`，13px 小字对新底落到 3.94——等于把刚修掉的洞留在公开主页；而护栏当时只解析 `styles.css`，看不见它。已一并修正并把护栏扩到着陆页。**教训：亮色令牌有两套真源（`styles.css` 与 `site/index.html`），任何一轮改动都要同时过两处，护栏现在会强制这一点。**

**本轮没做的事（留档）**：只动明度与两个文字令牌，未引入结构性层级。若「发飘」的感受主要来自时间轴容器内部缺少停靠点，本轮不解决——那属结构改动，在 D15 park 范围内。
