## A. 句库内置进文字轮播（仓库内）

### 资产与部署

- `git mv site/support/packs/*.txt packs/`，字节不变。TXT 不加 SPDX 头：头部注释会被拆成一句。`LICENSING.md` §1 的「Every runtime file carries an SPDX header」改准为「每个运行时代码文件」；句库与 D35 一样随项目许可证公开。
- `sw.js` 的 `FILES`、`project_audit.py` 的 `REQUIRED_RUNTIME_ASSETS` 各加 6 个路径；`build_legacy_site.py` 的 `RUNTIME_PATHS` 加 `packs`，使旧站发布前的运行时比较覆盖它；`CLAUDE.md`「项目性质」的运行时清单加 `packs/`。
- 句库 id（`focus` / `rest` / `restart`）和展示顺序只在应用代码里定义一次，文件名为 `packs/<id>-<lang>.txt`。audit 对每个 id × 语言检查文件存在且已进 `FILES`；缺任何一个就报错，并点名缺的文件。
- `build_site.py` 按 `FILES` 自动把它们组装到 `/app/packs/`，不新增映射。

### 交互

- **位置**：文字轮播面板「从文件导入」下方，一组「主题句库」，列出当前界面语言的三套。按钮文字复用支持页标题，例如「把注意力放回来 · 14 句」。单句格言面板不变。
- **点一下**：读取 `./packs/<id>-<lang>.txt`（SW 已预缓存，离线可用）→ `splitQuoteText` 拆句 → 只追加文本框里还没有的句子（去掉首尾空白后逐字比较）→ 刷新计数。
- **重复点击**：整套都已在框里时不改文本框，只提示「这套句子已经都在文本框里」。
- **不自动保存**：不保存、不切换模式；取消就丢弃。「完成」走现有的 `saveQuotesChecked`，1000 句上限与截断提示照旧。
- **异步归属**：沿用 v1.6.2 `loadQuotesFile` 的规则，记住发起读取时的那个 textarea；读完时 sheet 已关闭或已重开，就丢弃结果和错误。建议抽出一个文件导入和主题句库共用的「把拆好的句子追加到这份草稿」函数；文件导入不加去重，行为不变。
- **读取失败**（例如 SW 尚未接管又断网）：行内提示「暂时读不到这套句库，联网后再试」，草稿不变。
- **不提赞助**：面板里不出现支持页链接、支付平台或任何赞助字样。
- **旧站**：实现前先确认旧 origin 现在能否打开格言 sheet。无论结果如何，旧站都不得出现可以保存的新入口（SPEC-002 只读规则）。
- **文案**：新增的 key 中英对等，包括分组标题、三套名称、按钮读屏名、已存在提示、读取失败；不改既有 key 的含义。
- **键盘与触控**：三个按钮都能 Tab 到，Enter / Space 触发，沿用 `cell-action` 的 44px 热区。

## B. 平台致谢（仓库外，维护者操作）

AI 不登录平台、不代填后台，也不以维护者的名义编写经历或动机。

1. **前置确认**：维护者在爱发电与 Ko-fi 后台确认，是否有「付款后自动发给付款人」的消息或附件功能。哪个平台没有，就不做那个平台的致谢，也不自建替代。（AI 未核实这些功能。）
2. **内容由维护者写**：
   - 写明感谢，并重申所有功能免费、支持不购买优先权或产品方向。
   - 不承诺更新，不索要个人信息，不要求对方回复。
   - 可附一份一次性的不公开内容，托管在平台上。
   - 语言：爱发电用中文，Ko-fi 用英文；也可都用双语，由维护者定。
3. **存放位置**：只在平台后台。本机草稿可以放被 `.gitignore` 忽略的 `推广/`（D33）。本机目前没有这个目录，私有目录也不随仓库同步，所以平台后台是唯一真源。
4. **不进仓库与站点的内容**：消息原文、不公开内容及其链接、后台截图、支持者昵称、人数、金额。
5. **公开页**：不写致谢内容。「付款时可在平台选择匿名」这一句，要等维护者确认平台确有这个选项后才加，中英同批。
6. **验证口径**：后台保存或预览成功，只算「已配置」；是否真的送达，只有实际付款才能证明，要不要花这笔钱由维护者决定。STATUS 分开登记，不把「已配置」写成「已验证送达」。

## 实现记录（2026-11-10，v1.7.0 本地）

- **旧站核实**：旧 origin 现在能从「更多」与格言行打开格言 sheet，既有文件导入也能保存句库。本版不改这一既有行为，只是不在旧站渲染「主题句库」（`isLegacyOrigin` 的传递范围加上 `motto`）。
- **单复数**：英文「已追加」提示按 one/other 拆键（`quotes.packAddedOne/Other`），中文两键同文。
- **测试与 A 节第 6 条的偏差**：Playwright 的 WebKit 断网模拟会让所有请求失败，连已预缓存的 `src/app.js`、`styles.css`、`icon.svg` 也读不到（Chromium 同一探针全部 200）。因此离线用例只在 Chromium 运行，WebKit 离线列为真机项，不写成已覆盖。
- **部署测试**：`test_build_site.py` 新增真实仓库组装断言（`/app/packs/` 逐字节一致、`support/packs` 不存在）；`test_build_legacy_site.py` 新增「tag 之后改动 `packs/` 被拒绝」，并做过反向验证：从 `RUNTIME_PATHS` 去掉 `packs` 后该用例失败。
- **反向验证**：去掉 `addQuotePack` 读取后的草稿归属判断，延迟结果/错误两条用例在双引擎共 4/4 失败；恢复后通过。
