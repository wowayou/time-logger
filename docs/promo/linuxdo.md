## 1 · 这个社区关心什么（决定讲哪些方面）

linux.do 的读者以开发者、自托管/隐私偏好者、重度 AI 工具用户为主。按他们的兴趣排序，正文建议覆盖这六块，篇幅按顺序递减：

1. **它解决什么问题**（一段话）：说不清「昨天到底干了什么」；自动统计分不清在做正事还是在逃避；只有当下记一句话才拿得到真实信息。
2. **和常见工具的区别**（3–4 条）：记「做了什么」这句话而不是开始/停止计时；四桶归类（主线/维持/偏航/未记录）；「未记录」诚实显示、不凑 100%；漏记能补、记错能切。
3. **数据与隐私**（这个社区最在意）：纯本地 `localStorage`、无账号无后端无统计无第三方脚本；隐私政策把用到的每一个存储键都列出来了；完整备份是一个 JSON 文件，随时导出。
4. **工程实现**（开发者会点进仓库看）：原生 HTML/CSS/JS + ES modules，零构建、零运行时依赖；Service Worker 离线；双引擎（Chromium + WebKit）Playwright 全量回归；AGPL-3.0-or-later。
5. **和 AI 的关系**（可选，二选一或都写）：
   - 使用侧：当前视图可导出 Markdown 摘要、「时间分析」可复制本期摘要，直接贴给 AI 复盘——AI 只拿到你主动复制的那段文字，应用本身不联网。
   - 开发侧：这个项目是在 AI 编码代理辅助下写的，靠仓库里的规范文件（`CLAUDE.md`）、audit 脚本和测试门禁约束它，做过一次「另一台机器独立验收、发现数据丢失 bug、出补丁」的完整流程。**写这一段前想清楚是否愿意公开讨论这个开发方式**；写的话只讲事实，不评价 AI 工具优劣。
6. **诚实边界 + 想要的反馈**：个人自用工具、没做过外部验证、不做多设备同步；最想听到的是「你试了之后哪一步卡住了」。

**不要讲**：用户数、「很多人在用」、与某某产品的优劣比较、未来会做什么功能、支持作者。

## 3 · 正文（草）

佬友们好，分享一个自己一直在用的小工具，开源，纯网页（PWA），想听听大家的使用反馈。

**起因**：我经常说不清「昨天到底干了什么」，尤其是会议之间的大段空白。屏幕时间类工具能告诉我某个 App 用了多久，但分不清那段时间是在推进正事还是在逃避正事——真正有用的信息，只有自己当下记一句话才拿得到。

**它做什么**：

- 做完一阵，点「＋ 记一条」写一句「刚才在做什么」，选个标签就行。「5 秒记一条」是设计目标，我自己的实际耗时还没严格测过。
- 时间归到四个桶：**主线**（你当前要推进的事）、**维持**（睡觉吃饭通勤这类必要消耗）、**偏航**（偏离主线的时间，不做道德评判，放空也是必要的）、**未记录**。
- 没记的时间会**老实显示为「未记录」**，不会被四舍五入进别的桶，也不会为了凑满 100% 悄悄消失。
- 漏记了点「补一下」；一段里其实混了别的事，就在编辑里「切一刀」——先看到切完的样子，再在一行滚轮里选开始和结束，不会动到别的记录。
- 「时间分析」看本周/本月/今年各桶和标签的时长、和上期同一时点比多了还是少了；记录天数不够时不硬做对比。
- 当前视图可以导出 Markdown 摘要，直接贴给 AI 帮你复盘——应用本身不联网，AI 只拿到你主动复制的那段文字。

**数据与隐私**：

- 所有记录只在浏览器本地 `localStorage`，没有账号、没有后端、没有统计、没有第三方脚本、没有 Cookie。
- 隐私政策里把应用用到的**每一个**存储键都列出来了（不是「等」），可以对照源码核实。
- 完整备份就是一个 JSON 文件，随时复制/下载/分享；换设备就导出再导入，导入会逐条校验、冲突逐条让你选。

**技术上**（给想看代码的佬友）：

- 原生 HTML/CSS/JS，浏览器原生 ES modules，**零构建、零框架、零运行时依赖**；Service Worker 离线缓存，断网照常记。
- 用 Playwright 在 Chromium + WebKit 双引擎跑全量 UI 回归，另有纯逻辑 smoke 和 JSDoc 类型检查。
- 许可证 AGPL-3.0-or-later。

**边界**（先说清楚，省得大家失望）：

- 这是个人自用工具，**没有做过任何外部验证**，也不知道对别人是否有用——这正是发这个帖子的原因。
- **不做多设备同步**，暂时也不打算做；要迁移就导出 JSON 再导入。
- iOS 上用 Safari 打开 → 分享 → 添加到主屏幕；安卓与桌面浏览器可以直接安装。

**最想要的反馈**：你试了之后，**哪一步让你停下来了**？记第一条时卡在哪、哪个词看不懂、哪个按钮找不到——比「好用/不好用」有用得多。

- 应用：https://time.eigentime.org/app/
- 源码：https://github.com/wowayou/time-logger
- 有问题欢迎在帖子里回复或提 issue。

## 5 · 预备回帖（发帖前写好，发帖后不用现编）

- **数据在哪？** 只在浏览器 `localStorage`，不上传、不追踪；首次加载与检查更新需要网络；完整备份随时导出 JSON。
- **能同步吗？** 不能，暂时也不打算做。导出 JSON 再导入即可，导入是逐条校验的安全合并。
- **为什么不做原生 App？** 网页版零安装门槛、离线可用；安卓壳在独立仓库里，还没上架。
- **和番茄钟/Toggl 有什么不同？** 它不要求你先按开始；做完再记一句「刚才在干嘛」，时间自然接上。重点是四桶和「未记录」的诚实呈现，不是计时。
- **会不会收费/关停？** 源码开源、数据在本地、导出不依赖任何服务；就算我停更，你的数据和代码都还在。
- **为什么是 AGPL？** 希望基于它改的网页服务也保持开源；个人自用不受影响。
